PROTOTYPE — THROWAWAY 純前端記憶體模擬

App 連上 Origin Session 時，這份契約摸起來對嗎？

這個邏輯原型要回答：一份不含祕密的 App Manifest，加上一次性 launch grant、記憶體內 App Instance capability、HTTP Receipt、SSE Delivery Ack／Feedback，是否足以讓一般使用者理解 self-contained HTML 與既有 localhost App 的完整往返，同時看得出哪些動作不能成立。

不可跨越的界線：App Event、結構化問題的「同意」、Event Receipt、Delivery Ack 與 Agent Feedback 都不是 tool approval，也不能擴大 sandbox、permission 或工作 scope。本原型完全沒有 approval relay。

完整模擬狀態

每次操作後全部重新呈現；祕密只顯示遮罩與是否存在。
